A simple and lightweight Java console application that I built as part of the Programming in Java flipped course.
This project helps users manage their daily expenses in an easy and organized way — you can add new expenses, view all records, categorize them, or delete entries whenever needed.

I built the entire project using core Java concepts like classes, objects, constructors, methods, and ArrayList, keeping the structure clean and beginner-friendly.

The application is divided into three main classes:

Main.java – Handles the menu, takes user input, and guides the interaction flow.

Expense.java – A simple model class that represents each expense entry.

ExpenseManager.java – Contains all the logic for adding expenses, showing them, deleting them, and calculating totals.

I tried to follow a clear and modular design so that the code is easy to read, understand, and maintain.

I’ve also added screenshots in the /screenshots folder as proof of execution for evaluation.

Overall, this project is my small attempt at applying the basics of Java to solve a real, everyday problem in a simple and practical way.
